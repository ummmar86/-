Подробное описание

Математическое ядро сервера: метод половинного деления и метод Ньютона.

Все методы статические, объект класса создавать не нужно. Поддерживаемые уравнения (REQ-MATH-1):

funcId Уравнение Производная
0 x^2 - 4 2x
1 sin(x) - x/2 cos(x) - 1/2
2 e^x - 2 e^x

◆ solveBisection()

double MathSolver::solveBisection ( std::function< double(double)> f,
double a,
double b,
double eps,
bool & success )
static

Находит корень методом половинного деления (дихотомии).

Отрезок [a, b] делится пополам, пока его длина не станет меньше eps. На концах отрезка функция должна иметь разные знаки (BR-4).

Аргументы
fФункция, корень которой ищется.
aЛевая граница отрезка.
bПравая граница отрезка.
epsТребуемая точность (длина итогового отрезка).
[out]successtrue — корень найден; false — f(a)·f(b) >= 0.
Возвращает
Приближённое значение корня (0, если success == false).
Ошибка

Дефект №4: при a > b цикл не выполняется ни разу и возвращается a как «корень» (например, для x^2-4 на [5, 0] возвращается 5).

Дефект №5: при eps <= 0 возвращается число вместо статуса FAILED (требование ROB-1, BR-3).

Находит корень методом Ньютона (касательных): x_{n+1} = x_n - f(x_n)/f'(x_n).

Аргументы
fФункция.
dfПроизводная функции.
x0Начальное приближение (сервер передаёт (a+b)/2, BR-5).
epsТочность: итерации прекращаются, когда |x_{n+1} - x_n| <= eps.
[out]successtrue — метод сошёлся; false — производная близка к нулю (|f'(x)| < 1e-12) или превышено число итераций.
maxIterМаксимальное число итераций (по умолчанию 1000).
Возвращает
Приближённое значение корня.
