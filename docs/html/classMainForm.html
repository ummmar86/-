Подробное описание

Окно вычислений (UI-2).

Содержит список уравнений functionCombo, поля aEdit, bEdit, epsEdit, кнопку Solve и поля только для чтения bisectResult и newtonResult.

◆ on_stepButton_clicked

void MainForm::on_stepButton_clicked ( )
privateslot

Один шаг метода Ньютона: x1 = x0 - f(x0)/f'(x0).

Берёт уравнение из functionCombo, x0 из x0Edit и (необязательно) f'(x0) из dfx0Edit, отправляет "step <funcId> <x0> [<f'(x0)>]" и показывает x1 в stepResult. Если поле f'(x0) пустое, производную считает сервер. Некорректный ввод не отправляется на сервер.
