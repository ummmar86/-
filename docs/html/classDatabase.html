Подробное описание

Доступ к базе данных mathserver.db (паттерн «Одиночка»).

Таблицы:

  • Users (login TEXT PRIMARY KEY, password TEXT) — учётные записи;
  • History (id, login, functionId, a, b, eps, bisectionResult, newtonResult) — история расчётов.

Все запросы используют подготовленные выражения (prepare/bindValue), поэтому SQL-инъекции через логин и пароль невозможны.
