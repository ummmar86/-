Подробное описание

TCP-соединение клиента с сервером 127.0.0.1:33333 (паттерн «Одиночка»).

Формы отправляют команду через sendMessage() и сразу ждут ответ через getMsg().

Ошибка
Дефект №10: подключение выполняется только здесь, один раз. Если сервер был недоступен при запуске клиента, клиент не переподключается, а форма показывает «Login failed» вместо сообщения об отсутствии связи.
