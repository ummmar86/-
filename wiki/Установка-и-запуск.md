# Установка и запуск

## Требования

- Qt 5.15 или 6.x с модулями Core, Network, Sql, Widgets, Test и драйвером SQLite
- Компилятор с поддержкой C++17 (MinGW / MSVC на Windows, g++ / clang на Linux и macOS)
- Свободный TCP-порт **33333**

## Сборка в Qt Creator

1. `File → Open File or Project…` → открыть `MathServer/MathServer.pro`.
2. Так же открыть `MathClient/MathClient.pro`.
3. Собрать и запустить **сначала сервер**, потом клиент.

> Важно: клиент подключается к серверу один раз — при запуске. Если сервер запустить позже,
> вход будет выдавать «Login failed», пока клиент не перезапустить (см. [[Известные дефекты]], №10).

## Сборка из консоли

```bash
mkdir build-server && cd build-server
qmake ../MathServer/MathServer.pro
make                    # на Windows с MinGW: mingw32-make
./MathServer
```

В логе сервера должно появиться `Server is started on port 33333`. Файл базы
`mathserver.db` сервер создаёт сам в текущей папке.

```bash
mkdir build-client && cd build-client
qmake ../MathClient/MathClient.pro
make
./MathClient
```

Клиент подключается к `127.0.0.1:33333`.

## Запуск сервера в Docker

```bash
docker build -t mathserver .
docker run -d -p 33333:33333 -v mathserver-data:/data --name mathserver mathserver
```

или одной командой:

```bash
docker compose up -d
```

- При `docker build` собираются сервер и оба проекта тестов, тесты запускаются. Если хоть один тест
  упадёт, образ не соберётся.
- База `mathserver.db` хранится в томе `/data`, поэтому пользователи и история не пропадают
  при пересоздании контейнера.
- Клиент — графическое приложение, он запускается на компьютере как обычно и подключается к порту 33333.

Остановить сервер: `docker stop mathserver` (или `docker compose down`).
