# Архитектура

```
MathClient (Qt Widgets)  ──TCP 127.0.0.1:33333, UTF-8──▶  MathServer (консольный)
  AuthRegForm, MainForm                                       MyTcpServer
  ClientController                                            CommandParsing
  MyTcpClient                                                 MathSolver, Database ──▶ mathserver.db (SQLite)
```

## Сервер (MathServer)

| Класс            | Назначение |
|------------------|------------|
| `MyTcpServer`    | Слушает порт 33333, принимает подключения, передаёт каждую полученную строку в `CommandParsing` и отправляет ответ |
| `CommandParsing` | Разбирает команды `reg`, `auth`, `solve` и формирует ответ (см. [[Протокол]]) |
| `MathSolver`     | Статические методы: `solveBisection`, `solveNewton`, `newtonStep`, уравнения и их производные |
| `Database`       | Одиночка (Singleton): регистрация, вход, запись истории в SQLite |

![Диаграмма классов сервера](https://raw.githubusercontent.com/SymenSoul/TechProg_RootFinder/main/docs/diagrams/class_server.png)

## Клиент (MathClient)

| Класс              | Назначение |
|--------------------|------------|
| `AuthRegForm`      | Стартовое окно: логин, пароль, кнопки Login и Register |
| `MainForm`         | Выбор уравнения, поля a, b, eps, кнопка Solve, результаты, Logout |
| `ClientController` | Одиночка: собирает строки команд и разбирает ответы сервера |
| `MyTcpClient`      | Одиночка: TCP-сокет, `sendMessage()` и синхронное чтение ответа `getMsg()` |

## База данных

Файл `mathserver.db` создаётся сервером при первом запуске.

**Users**

| Поле     | Тип  | Описание                  |
|----------|------|---------------------------|
| login    | TEXT | Логин, первичный ключ     |
| password | TEXT | Пароль                    |

**History**

| Поле            | Тип     | Описание                         |
|-----------------|---------|----------------------------------|
| id              | INTEGER | Номер записи, автоинкремент      |
| login           | TEXT    | Кто выполнил расчёт              |
| functionId      | INTEGER | Уравнение: 0, 1 или 2            |
| a, b            | REAL    | Границы интервала                |
| eps             | REAL    | Точность                         |
| bisectionResult | REAL    | Корень по методу половинного деления |
| newtonResult    | REAL    | Корень по методу Ньютона         |

Все SQL-запросы с логином и паролем выполняются через `prepare` / `bindValue`, поэтому
SQL-инъекции через поля ввода невозможны.

Пример отчёта по истории пользователя (MATH-RPT-1 из спецификации):

```sql
SELECT * FROM History WHERE login = 'student' ORDER BY id;
```
